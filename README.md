
# Smart Task Manager

## Web Development Project

Smart Task Manager is a responsive web application
built using HTML, CSS, and JavaScript.

## Objective
To develop an interactive task management website
and demonstrate frontend development skills.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter by completion status
- Filter by priority
- Task statistics dashboard
- Dark and light mode
- Local Storage support
- Responsive design
- Form validation

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Start adding and managing tasks.
